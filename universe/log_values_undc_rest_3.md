## Anomalies and notes

1. **PT_CM_IPV_12M (NGA 2024 = 59.2)** is identical to PT_CM_EMPLOY_12M (NGA 2024 = 59.2). 59.2% past-12-month IPV among never-married women 20-24 is implausible; looks like a source mislabel. Recorded verbatim; flag before use.
2. **Unit mislabel**: PV_CHLD_DPRV_AVG_HS, PV_CHLD_DPRV_AVG_POV_HS, PV_CHLD_DPRV_AVG_POV_S_HS, PV_CHLD_DPRV_AVG_S_HS are "average number of deprivations" (values 0.69-1.96) but the server reports unit "Percent".
3. **Duplicate series under two codes**: SPP_VMI == PV_VMIR for all three countries (NGA 2010 0.63775; IND 2012 0.694625; BRA 2017 0.527625). SPP_CHLD_POV_PROF.POVERTY_THRESHOLD--D_1 (NGA 2018 34.44917679; IND 2015 37.95131683) equals PV_CHLD_DEPRV_S.NUMBER_OF_DEPRIVATIONS--E1 at lower precision (34.44917678833008; 37.951316833496094).
4. **Modelled/carried-forward WASH series** (JMP-style): WS_HCF_WM NGA 2010-2023 is a piecewise-linear path (flat 2010-2012, linear steps, down to 4.645 in 2023); WS_SCH_H-F NGA constant 39.10454 for 2012-2023, BRA constant 99.11904 for 2011-2019, IND flat 18.2177 for 2007-2011 then linear climb to 100 in 2022-2023; WS_SCH_S-I and WS_SCH_W-I NGA flat 2007-2011 then linear; WS_PPL_S / WS_PPL_W_DW are smooth annual 2000-2024 series. WS_PPL_W_DW limited-service BRA reaches exactly 0 in 2022-2024.
5. **PV_LEVEL.VALUE_CATEGORY--CAT_LOW** is a binary flag (unit CATEGORY_BINARY_TF); only BRA 2011 = 1 returned. NGA/IND presumably sit under other VALUE_CATEGORY DCIDs.
6. **PT_NMRD** (never married, 15-17, female, not attending school): values NGA 38.3 / IND 22.4 / BRA 13.6 — read the disaggregation carefully; recorded as returned.
7. **PT_F_TMRD15** counts appear rounded to 100,000s (NGA 10600000; IND 90500000; BRA 3500000) — as returned.
8. Brazil's child-marriage/CM module values mostly date from 2006 (PNDS); India's from 2021 (NFHS-5); Nigeria's from 2024 (DHS 2023-24) or 2021 (MICS). Several per-country latest years therefore differ by up to 18 years.
